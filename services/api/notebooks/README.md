# Notebooks (reference only)

`halo_avatar_preprocessing.py` is the Google Colab export of the original HALO avatar
preprocessing experiment. It is **not imported** by the backend. The production code
lives in `app/ai/avatar/` (see `docs/AI_MODELS.md` for what changed and why).

Do not commit `.ipynb` files with outputs: Colab outputs embed the test photos.
`*.ipynb` in this folder is git-ignored for that reason.
